iPhone (Команды)

  1. Открой “Команды” → “Автоматизация” → “Время суток” (например 07:00 ежедневно).
  2. Добавь действие “Получить содержимое URL” и вставь URL из поля выше.
  3. Добавь действие “Установить обои” (экран блокировки или оба).
  4. Выключи “Спрашивать перед запуском”.
  5. Обновление каждые 5–10 минут на iOS системно не гарантируется. Реалистично — несколько обновлений в день (утро/день/вечер) или обновление по триггерам (например при открытии/закрытии режима фокусировки).
  6. Быстрый запуск без таймера: Настройки → Универсальный доступ → Касание → “Касание задней панели” → выбрать команду (двойной/тройной тап).
  7. Если есть Action Button: Настройки → Action Button → “Shortcut” → выбрать команду.
  8. Комбинации аппаратных кнопок (громкость + и - и т.п.) привязать нельзя.

Android (Tasker/Automate)

  1. Сделай триггер по времени (например каждые 5–10 минут).
  2. HTTP GET по URL из поля выше → сохранить в файл (wallpaper.png).
  3. Действие “Set Wallpaper” → lock/home.
  4. Триггер на “блокировку”: в Tasker обычно это Event → Display → Display Off (или Screen Off) → дальше те же шаги.
Токен в URL живёт ~30 дней. Если сервер недоступен с телефона — нужен домен/туннель/VPN.
